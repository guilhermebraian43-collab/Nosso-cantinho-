# Nosso Cantinho 💜

Site romântico de exibição, feito para ser simples de modificar e publicar no GitHub Pages.

## Estrutura

- `index.html` = textos e estrutura
- `style.css` = aparência
- `script.js` = contador, música e corações
- `imagens/` = coloque suas fotos aqui
- `audio/musica.mp3` = coloque sua música aqui

## Fotos

Coloque quatro fotos na pasta `imagens` com estes nomes:

- foto1.jpg
- foto2.jpg
- foto3.jpg
- foto4.jpg

Você pode trocar os nomes no `index.html` se preferir.

## Música

Por questões de direitos autorais, o projeto não inclui a música. Coloque o arquivo que você possui em:

`audio/musica.mp3`

O botão da página tocará esse arquivo.

## Contador

A data atual configurada é:

01/03/2025

Para mudar, abra `script.js` e altere:

const inicio = new Date("2025-03-01T00:00:00");

## GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos mantendo as pastas.
3. Vá em Settings > Pages.
4. Em Source, escolha Deploy from a branch.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde o GitHub publicar.
